实时观察一键启动

唯一启动文件：start_live.sh
默认机器人：172.18.21.239
默认 SSH 用户：nvidia
展示地址：http://127.0.0.1:8771/?source=live

使用
1. 机器人开机，电脑与机器人网络互通；原有 live_stream 相机接口已在运行。
2. 在项目根目录运行 ./start_live.sh，或在文件管理器中选择“在终端运行”。
3. 只读 VLA 采集器未运行时，脚本通过 SSH 启动独立新增文件夹内的 start_observer.sh。
   不调用原相机或技能启动脚本，不修改机器人任何原有文件、配置或启动命令。
   若终端提示 password，输入机器人账号的 SSH 密码。输入时不显示字符是正常的。
   项目不保存密码；已配置可用 SSH 密钥时不需要输入密码。
4. 等待三路有效画面。脚本随后接收快照、接收独立 VLA 事件、启动展示服务、自动打开实时观察。
5. 保持终端开启。Ctrl+C 停止电脑端接收及本次新启动的展示服务。
   已启动的机器人相机桥保持运行；不会在退出时关闭它。

参数
./start_live.sh --robot-ip 172.18.21.239
./start_live.sh --robot-user nvidia --ssh-port 22
./start_live.sh --port 8773
./start_live.sh --no-browser
./start_live.sh --no-vla                     # 仅使用原三路相机
./start_live.sh --vla-port 8774              # 默认只读 VLA 旁路端口

只接收，不执行任何 SSH 启动（相机桥与 VLA 旁路都需已运行）
./start_live.sh --no-ssh

只检查当前画面，不执行 SSH、不写快照、不启动任何服务
./start_live.sh --check

独立采集器默认路径
/home/nvidia/r1_exhibit_observer/start_observer.sh
新增程序、spool、日志、PID均在 /home/nvidia/r1_exhibit_observer/ 内。
原协调器 runtime 只读；首次复制采集器后即可使用，不需要修改或重启控制程序。

执行边界
- 端口已运行：直接等待画面，不执行机器人重启脚本。
- 相机端口未运行：只等待和提示，不运行原机器人脚本。VLA旁路端口未运行：最多启动一次独立新目录里的采集器。
- 接口返回空快照：等待出帧并提示相机尚未就绪，不反复重启。
- 运行中断流：继续尝试读取，旧画面按原始时间过期；不会在后台反复执行 SSH。
- SSH 使用系统 OpenSSH，保留主机密钥检查，不保存密码。首次连接可能需要核对主机指纹。
- 不安装依赖，不修改原源码/配置/日志，不启动 VLA 或动作；新采集器只读取原有JSONL、NPZ、SUMMARY。
- 本机快照为 ~/r1pro_live/snapshot.json；约每秒一帧，保留机器人原始采集时间。
- 本机 VLA 记录默认保存至快照旁的 vla.sqlite3；切屏、关闭浏览器不影响运行中的后台接收。
- VLA 旁路端口未监听时，通过 SSH 调用独立目录内的 start_observer.sh；失败不阻断相机。仅首次安装需技术人员部署，启动器不会安装或修改机器人源码。
- VLA 旁路只读已有运行日志/观测附件，不启动模型、协调器、技能或运动。退出展示接收器不停止机器人侧旁路或控制进程。
- 启动配置增加了独立 VLA 数据库；若旧展示服务占用8771且没有此配置，用 --port 8773 启动新版，或由原终端退出旧服务后再启动。

实时 VLA 内容
- 现有三路相机保持原样；右侧展示当前请求输入、动作预测、实际下发、发送前/独立反馈与结果证据。
- “实时 VLA 请求与执行证据”可展开查看 state23、action23、实际请求图像、模型返回文本和细分耗时。
- 已在运行的旧控制进程可通过只读日志旁路显示，界面标注“旧日志”；没有请求开始记录时不虚构推理过程。请求开始/取消等原日志未记录的信息明确显示未知；不会安装遥测钩子。
- 运行结束、停止和回位分别显示。没有独立抓稳/入筐结果判定时，任务结果保持待核验。
- 真机回放、模型推理回放（2界面）、原记录及其播放/跳转功能保持不变。
- 独立目录安装、停止和旁路参数见 robot_side/README.md；只读数据接口见 exhibit/LIVE.md。

故障提示
Connection refused：检查现有相机接口或独立VLA旁路是否在运行；启动器不会改动或重启原相机。
Permission denied：检查 SSH 用户名、密码或密钥。
旁路脚本不存在：检查 --vla-bridge-script 指定的新目录；启动器不会上传文件。
空快照 / bytes:2：桥已运行但相机未出帧，查看机器人原有日志和相机状态。
时间过期或超前：检查画面更新和两端时钟。
端口冲突：换 --port 8773，或先关闭原展示服务；不会强杀其它程序。
重复启动：使用已有窗口；同一个快照文件只允许一个本机接收启动器。
